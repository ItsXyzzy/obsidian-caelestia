# Changelog

All notable changes to this theme are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/), and this project adheres to
[Semantic Versioning](https://semver.org/).

## [1.0.0] — 2026-10-12

### Added

- Initial release.
- Material 3 light & dark palettes generated from a live Caelestia scheme.
- Caelestia design tokens: rounding (`4/8/12/16/20/28/32/48/full`), the shell
  spacing scale, and Material emphasized easing.
- Squircle corners via CSS `corner-shape: superellipse`.
- Translucent, blurred menus, prompts and modals.
- Floating rounded panes for sidebars and note areas.
- Bundled Rubik typeface (SIL OFL 1.1).
- Style Settings controls for accent, rounding, corner shape, translucency,
  floating panes and reading width.
- Full coverage of editor, reading view, callouts, embeds, tables, code,
  properties, tags, Bases, Canvas and graph.
- `scripts/sync-scheme.mjs` to regenerate the palette from Caelestia.
